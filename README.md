# 🦖 Тренажёр динозавров

Игра-тренажёр таблицы умножения для ребёнка 7–10 лет. Решаешь примеры — набираешь
опыт, трескаешь яйцо, вылупляешь динозавра. Двадцать динозавров, семь уровней
игрока, двенадцать ачивок.

Весь код — один файл `index.html` без сборки, зависимостей и сети. Открывается
двойным кликом и работает офлайн.

## Как играть

Открой `index.html` в браузере — или зайди на опубликованную страницу, если она есть.

При первом запуске игра спросит имя. Дальше: кнопка **ПОИГРАТЬ** запускает раунд
из 10 примеров. Ответ вводится с клавиатуры (Enter) или кнопкой **Проверить**.

- ответ быстрее 5 секунд — 10 XP, медленнее — 5 XP;
- три быстрых правильных подряд — пример считается выученным;
- ошибка снимает статус «выучено», пример возвращается в ротацию;
- выученное возвращается на повторение через 3 дня;
- каждые 25 правильных ответов вылупляется динозавр;
- 80% выученных примеров тира открывают следующий: ×1 ×2 ×5 ×10 → +×3 ×4 → +×6…×9.

Примеры подбираются по весам: то, где ошибался, спрашивается чаще, свежевыученное
не спрашивается вовсе.

## Прогресс

Хранится в `localStorage` — то есть в одном конкретном браузере и отдельно для
каждого адреса (локальный файл и сайт не делят прогресс). Чтобы перенести или
подстраховаться: ⚙ → **Сохранить прогресс в файл**, потом **Загрузить из файла**.

## Служебные режимы

| Адрес | Что делает |
|---|---|
| `index.html?test=1` | прогоняет встроенные тесты и показывает отчёт |
| `index.html?dev=1` | панель разработчика: выдать прогресс, вылупить яйцо, перевести часы, проверить картинки |

## Структура

```
index.html          вся игра: движок, тесты, интерфейс
images/             20 динозавров, WebP 1024px
images/thumbs/      превью 256px для сетки коллекции
bak/                дизайн-документ и старая версия
```

Оригинальные PNG (83 МБ) и архив проекта в репозиторий не входят — см. `.gitignore`.

## Публикация

Статика без сборки, поэтому GitHub Pages: Settings → Pages → Deploy from a branch →
`main` / `(root)`. Имена файлов картинок в нижнем регистре — на Linux-хостинге это
принципиально.
