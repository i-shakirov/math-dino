# Локализация: выбор языка и корейский

Дата: 2026-09-20
Статус: дизайн на утверждении

## Задача

Добавить в тренажёр выбор языка и корейскую локализацию такого качества,
чтобы носитель языка не опознал в ней перевод.

Языки: русский (исходный), корейский, английский.

## Почему это не «прогнать строки через переводчик»

В коде 199 уникальных текстовых литералов, и почти все собираются
конкатенацией:

```js
banner('🎉 Открыт ' + TIER_NAMES[tier].toLowerCase() + ' уровень! Новые примеры: ' + list)
```

Для корейского такая склейка даёт мгновенно опознаваемый машинный текст,
и по трём причинам сразу.

**Порядок слов.** Корейский — SOV: сказуемое уходит в конец, и русская
рамка «Открыт X уровень! Новые примеры: Y» не переставляется подстановкой.
Предложение должно писаться целиком на корейском.

**Частицы.** После существительного идёт падежная частица, и её форма
зависит от того, кончается ли слог согласной: `트리케라톱스가`, но
`이구아노돈이`. Из двадцати наших динозавров девятнадцать требуют `가` и
ровно один — `이`. Зашитая в шаблон частица сломает один экран из двадцати:
это самый неприятный вид ошибки, потому что при беглой проверке его почти
наверняка не встретишь.

**Счётные слова.** Форм числа в корейском нет, но при числительном
обязателен счётный суффикс, и он разный по роду предмета: `문제 3개`,
`공룡 3마리`, `업적 3개`, `5일 연속`. Нынешняя `plural(n, one, few, many)`
с русской тройкой внутри этого не выражает.

## Решение

Данные очищаются от текста, текст переезжает в словари, адресуемые по `id`.
Единственная точка выдачи текста — `t(key, params)`.

### Слой локализации

Новая секция `=== SECTION: I18N ===` в `index.html`, между `CONSTANTS` и
`TEST INFRA`. Содержит: список языков, детектор, `t`, `josa`, плюрализатор
и три словаря.

**`t(key, params)`** достаёт строку из активного словаря и подставляет
`{placeholder}`. Значение может быть строкой либо объектом категорий
множественного числа — тогда категория выбирается по `params.n`.

Отсутствующий ключ: в обычном режиме `t` возвращает русский вариант
(русский — источник истины), а если нет и его — сам ключ. В `?test=1` та
же ситуация выбрасывает исключение. Пропущенный перевод не доедет до
игрока молча и не спрячется от тестов.

**Плюрализация** — через `Intl.PluralRules`, встроенный в браузер, без
зависимостей и без сети. Значение счётного ключа — объект по категориям
CLDR:

```js
questionsToRepeat: { one: '{n} пример', few: '{n} примера', many: '{n} примеров' }   // ru
questionsToRepeat: { one: '{n} problem', other: '{n} problems' }                     // en
questionsToRepeat: { other: '{n}문제' }                                              // ko
```

Корейский всегда попадает в `other`; счётный суффикс написан прямо в
шаблоне, потому что это лексика, а не морфология. Функция
`plural(n, one, few, many)` удаляется вместе с её русскими правилами.

**`josa(word, 'пара')`** возвращает слово вместе с нужной частицей
(`josa('이구아노돈', '이/가')` → `이구아노돈이`), выбирая её по наличию
финальной согласной в последнем слоге. Считается арифметикой по коду
хангыля: `(code - 0xAC00) % 28 !== 0` означает, что согласная есть.
Поддерживаемые пары: `이/가`, `은/는`, `을/를`, `과/와`, `으로/로`. Слово,
не оканчивающееся слогом хангыля, получает первую форму пары.

Жёсткое ограничение: **`josa` применяется только к нашим собственным
существительным** — именам динозавров, названиям тиров и уровней. К имени
игрока никогда: там может оказаться «Юлиана» или «Anna», и угадывать
частицу по нехангыльному слову значит гарантированно ошибаться. Поэтому
корейское приветствие — `안녕하세요, {name}!`, без вокативной частицы
`아/야`, которая как раз потребовала бы хангыля.

### Правила корейского текста

Это часть спеки, а не вкусовщина: именно они отличают текст от перевода.

Регистр — **해요체**, единый по всему приложению. Смешение уровней
вежливости внутри одного экрана — главный маркер машинного перевода.

Кнопки и заголовки — отглагольными существительными: `설정`, `저장`,
`취소`, `확인`, `불러오기`, `초기화`. Так пишут корейский интерфейс
независимо от регистра реплик.

Условия ачивок — формой на `~기`: `정답 10개 연속 맞히기`. Это принятый в
корейских играх способ писать условие.

Второго лица нет. `당신` и `너` в корейском интерфейсе не употребляются;
там, где русский говорит «ты», корейский либо опускает подлежащее, либо
перестраивает фразу.

Запрещены кальки-번역투: избыточный пассив, обороты вида `~를 위한` и
`~에 대한` там, где корейский обошёлся бы без них, прямой перенос русской
пунктуации (тире вместо связки).

Пробелы (띄어쓰기) по норме Национального института корейского языка.

Числа — арабскими цифрами со счётным суффиксом: `공룡 3마리`, не `세 마리`.
В детских приложениях пишут именно так, и это снимает вопрос выбора между
исконными и китайскими числительными.

### Шрифт

`Comic Sans MS` не содержит хангыля. При нынешнем стеке корейский текст
проваливался бы в системный шрифт **посимвольно**: цифры остались бы в
Comic Sans, буквы ушли бы в Malgun Gothic — в одной строке две гарнитуры.

Поэтому при корейском языке шрифт переключается целиком:

```css
html[lang="ko"] body { font-family: 'Apple SD Gothic Neo', 'Malgun Gothic', 'Noto Sans KR', sans-serif; }
```

Веб-шрифт не подключается: это убило бы работу без сети. Перечисленные
гарнитуры входят в состав macOS/iOS, Windows и Android соответственно.

### Именование ключей

Плоские точечные ключи, сгруппированные по экрану:

```
common.ok  common.cancel  common.save
hub.play  hub.tierUnlocked  hub.welcomeBack
trainer.check  trainer.correct  trainer.remember
round.title  round.correctCount  round.again
dino.velociraptor.name  dino.velociraptor.fact
ach.first-correct.name  ach.first-correct.desc
level.4  tier.1
settings.title  settings.changeName  settings.language
```

`id` динозавров, ачивок и номера уровней уже существуют в коде — словарь
переиспользует их, новой системы идентификаторов не заводится.

## Что меняется в существующем коде

`DINOS` теряет `name` и `fact`, остаются `id`, `image`, `emoji`.
`ACHIEVEMENTS` теряет `name` и `desc`, остаются `id`, `icon`.
`LEVEL_THRESHOLDS` теряет `name`. `TIER_NAMES` и `GREETINGS` исчезают как
константы и становятся ключами словаря.

Функция `levelName(level)` начинает читать из словаря. Хак
`TIER_NAMES[tier].toLowerCase()` — попытка получить русский косвенный
падеж — удаляется: каждое предложение теперь целиком живёт в словаре.

Около 220 мест отрисовки переписываются с конкатенации на `t()`.

Заодно чинится `'🎉 Ты выучила всё на этом уровне!'` — женский род,
оставшийся от одного конкретного игрока. В публичной версии русский
вариант становится нейтральным по роду.

Не переводятся и остаются русскими: комментарии в коде, имена тестов,
панель разработчика `?dev=1`. Это внутренние тексты, игрок их не видит.

## Состояние и миграция

`STATE_VERSION` 2 → 3. В состояние добавляется `settings.lang`.

Сохранения второй версии получают `lang: 'ru'` — они заведомо игрались
по-русски, и менять язык под уже играющим человеком нельзя.
Автоопределение работает только для нового сохранения.

Существующий механизм `Storage._migrate` / `_fillDefaults` дописывает поле
без потери прогресса — ровно так, как он уже делает это для `player.name`.

Экспорт и импорт прогресса переносят `settings.lang` вместе с остальным:
это собственное сохранение игрока, и язык — его часть.

## Интерфейс выбора языка

Определение при первом запуске: `navigator.language` → если начинается с
`ko`, `ru` или `en`, берётся он; иначе английский как наиболее вероятно
понятный.

Переключатель — компактный чип рядом с `⚙` в шапке хаба, подписанный
`한 · RU · EN` с выделенным текущим. Одно нажатие, понятно без слов, и
промах автоопределения чинится за секунду. Дубль пункта — в меню настроек,
где языки перечислены своими названиями: `한국어 / Русский / English`.
Названия языков не переводятся никогда.

Экран выбора языка перед игрой не показывается: он всё равно был бы на
каком-то одном языке, а лишний шаг между ребёнком и кнопкой «играть»
ничего не решает.

Смена языка перерисовывает хаб целиком и обновляет `<html lang>` и
`<title>`. В тренажёре чипа нет — язык не меняется посреди раунда.

## Тесты

Сейчас тестов 105. Часть переписывается (см. ниже), поэтому итоговое число
сместится; важно не оно, а то, что новых проверок ровно пять:

**Полнота словарей** — множества ключей `ru`, `ko`, `en` совпадают. Ни
пропусков, ни осиротевших ключей.

**Совпадение плейсхолдеров** — в одном ключе у всех трёх языков один и тот
же набор `{...}`. Ловит перевод, потерявший подстановку.

**Категории множественного числа** — для `n` от 0 до 200 у каждого
счётного ключа находится категория, которую вернул `Intl.PluralRules`.
Проверять именно перебором, а не по `pluralCategories`: у русского в
списке есть `other`, недостижимая для целых чисел, и требовать её значило
бы заставлять писать форму, которую никто никогда не увидит.

**`josa`** — `이구아노돈` → `이`, `트리케라톱스` → `가`, нехангыльное слово
возвращает первую форму и не падает.

**Отсутствие конкатенации** — в корейском словаре нет значений,
начинающихся или заканчивающихся пробелом: такой пробел выдаёт строку,
собранную из кусков.

Существующие тесты `greetingFor` и `plural` переписываются на новый слой:
`plural` как функция исчезает, `greetingFor` проверяется на всех трёх
языках.

Прогон — как и сейчас: `?test=1` в браузере и харнесс в Node.

Двадцать фактов и реплики тренажёра пишутся по правилам выше на этапе

| ru | ko |

| Самый быстрый — как ты, когда отвечаешь! | 가장 빠른 공룡이에요. 문제를 척척 푸는 모습이랑 닮았죠? |
| Длинный, как два автобуса | 버스 두 대를 이어 놓은 것만큼 길어요 |

| Правильно, но подумай быстрее. +{xp} XP | 정답이에요! 조금만 더 빠르면 좋겠어요. +{xp} XP |
| Запомни: {a} × {b} = {c} | 기억해요: {a} × {b} = {c} |
| 🎉 Открыт средний уровень! Новые примеры: ×3, ×4 | 🎉 보통 단계가 열렸어요! 새로운 문제: ×3, ×4 |

Последняя строка показывает суть: в русском «Открыт» стоит первым, в
корейском `열렸어요` — последним. Подстановкой из общей рамки это не
получается, и ровно поэтому предложение целиком лежит в словаре.

## Вне задачи

README остаётся русским. Перевод документации — отдельная работа, к
интерфейсу отношения не имеет.

Озвучка, форматирование дат, письмо справа налево, смена картинок под
язык — не нужны.

Четвёртый язык не добавляется. Архитектура его примет как один новый
объект-словарь, но делать это заранее незачем.

## Риски

Объём `index.html` вырастает примерно со 113 до 145 КБ. Обещание «один
файл, открывается двойным кликом» сохраняется. Если файл станет неудобным,
переезд на отдельные `i18n/*.js` после этой работы механический: словари
уже изолированы в своей секции.

Корейский текст некому вычитать носителем. Компенсируется двумя вещами:
правила выше зафиксированы письменно и проверяются тестами там, где
поддаются проверке; остальное — сплошная вычитка корейского словаря
отдельным проходом, читая только корейский, без взгляда на русский
оригинал.
