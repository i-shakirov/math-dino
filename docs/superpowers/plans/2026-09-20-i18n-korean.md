# План: локализация и корейский язык

> **Для исполнителя-агента:** ОБЯЗАТЕЛЬНЫЙ САБ-SKILL: используй
> superpowers:subagent-driven-development (рекомендуется) или
> superpowers:executing-plans, чтобы выполнять план задача за задачей.
> Шаги размечены чекбоксами `- [ ]`.

**Цель:** добавить в тренажёр таблицы умножения выбор языка и корейскую
локализацию такого качества, чтобы носитель не опознал в ней перевод.

**Подход:** весь текст уезжает из кода в три словаря, адресуемых по `id`;
единственная точка выдачи — `t(key, params)`. Конкатенация убирается
полностью: корейский SOV и падежные частицы не переносят сборку фразы из
кусков. Миграция идёт экраном за экраном, каждый шаг оставляет игру
работоспособной.

**Стек:** чистый JavaScript в одном `index.html`, без сборки и
зависимостей. Плюрализация — встроенный `Intl.PluralRules`. Тесты —
собственный мини-фреймворк в том же файле (`describe`/`it`/`assert`),
прогон через Node или через `index.html?test=1`.

**Спека:** [`docs/superpowers/specs/2026-09-20-i18n-korean-design.md`](../specs/2026-09-20-i18n-korean-design.md)
Читать вместе с планом: таблицы имён динозавров, ачивок, уровней и тиров
лежат в спеке и в плане не дублируются.

## Общие ограничения

Действуют на все задачи без исключения.

- Один файл `index.html`: без сборки, без зависимостей, без сети.
  Открывается двойным кликом с `file://` и работает офлайн.
- Веб-шрифты не подключать. Только системные гарнитуры.
- Корейский регистр — **해요체**, единый по всему приложению.
- Корейские кнопки и заголовки — именными формами: `설정`, `저장`,
  `취소`, `확인`, `불러오기`, `초기화`.
- Корейские условия ачивок — формой на `~기`: `정답 10개 연속 맞히기`.
- В корейском тексте не бывает `당신` и `너`.
- Корейские пробелы (띄어쓰기) — по норме Национального института
  корейского языка.
- Корейские числа — арабскими цифрами со счётным словом: `공룡 3마리`,
  `문제 5개`, `업적 2개`, `5일 연속`. Не `세 마리`.
- `josa` применяется **только** к собственным существительным игры —
  именам динозавров, названиям тиров и уровней. К имени игрока никогда.
- Русский — источник истины: при отсутствии ключа `t` отдаёт русский
  вариант, а в тестовом режиме бросает исключение.
- Содержание игры одинаково для всех языков: те же 100 примеров, те же
  три тира, те же пороги. Локализуется текст, не педагогика.
- Остаются русскими и не переводятся: комментарии в коде, имена тестов,
  вывод тест-раннера, панель `?dev=1`.
- Коммиты подписывать личной почтой `mailtoildar@gmail.com`
  (проверить `git config user.email` перед первым коммитом) и заканчивать
  строкой `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- Не пушить. Все коммиты локальные, отправку решает владелец репозитория.

**Номера строк** в плане — от коммита `4f36001`. После каждой задачи они
смещаются: ищи по тексту литерала, а не по номеру.

**Числа тестов** в плане заданы приростом, а не абсолютом: важно, что
`FAILED: 0` и что `PASSED` вырос ровно на число добавленных проверок.
Прирост меньше ожидаемого означает потерянный тест — это повод
остановиться, а не идти дальше. Отправная точка — 105 тестов.

```js
    // === SECTION: I18N ===

    const LANGS = ['ru', 'ko', 'en'];
    const LANG_NAMES = { ru: 'Русский', ko: '한국어', en: 'English' };
    const LANG_SHORT = { ru: 'RU', ko: '한', en: 'EN' };
    const DEFAULT_LANG = 'en';

    // Словари заполняются задачами 3–6 (ru), 9 (en) и 10 (ko).
    const I18N = { ru: {}, ko: {}, en: {} };

    let _lang = 'ru';
    function getLang() { return _lang; }
    function setLang(lang) { _lang = LANGS.includes(lang) ? lang : DEFAULT_LANG; }

    function _langFromTag(tag) {
      const code = String(tag || '').toLowerCase().slice(0, 2);
      return LANGS.includes(code) ? code : DEFAULT_LANG;
    }

    function detectLang() {
      return _langFromTag(typeof navigator === 'undefined' ? '' : navigator.language);
    }

    // Корейская падежная частица зависит от того, кончается ли последний
    // слог согласной (받침). Проверяется арифметикой по коду хангыля.
    const JOSA_PAIRS = {
      '이/가': ['이', '가'],
      '은/는': ['은', '는'],
      '을/를': ['을', '를'],
      '과/와': ['과', '와'],
      '으로/로': ['으로', '로']
    };

    function _jongseong(word) {
      const s = String(word == null ? '' : word);
      if (!s) return 0;
      const code = s.charCodeAt(s.length - 1);
      if (code < 0xAC00 || code > 0xD7A3) return 0;   // не слог хангыля
      return (code - 0xAC00) % 28;
    }

    function josaFor(word, pair) {
      const forms = JOSA_PAIRS[pair];
      if (!forms) return '';
      const jong = _jongseong(word);
      // (으)로 — исключение: после ㄹ (индекс 8) ведёт себя как после гласной.
      if (pair === '으로/로') return (jong === 0 || jong === 8) ? forms[1] : forms[0];
      return jong !== 0 ? forms[0] : forms[1];
    }

    const _pluralRules = {};
    function _pluralCategory(lang, n) {
      if (!_pluralRules[lang]) _pluralRules[lang] = new Intl.PluralRules(lang);
      return _pluralRules[lang].select(Number(n));
    }

    // Шаблон может быть строкой либо объектом форм числа.
    // {이/가} и подобные берут слово из предыдущей подстановки.
    function _render(value, params) {
      const p = params || {};
      let template = value;
      if (template && typeof template === 'object') {
        const cat = _pluralCategory(_lang, p.n);
        template = template[cat] !== undefined ? template[cat] : template.other;
        if (template === undefined) {
          if (isTestMode()) throw new Error('i18n: нет формы "' + cat + '" для n=' + p.n);
          template = '';
        }
      }
      let previous = '';
      return String(template).replace(/\{([^{}]+)\}/g, (whole, name) => {
        if (JOSA_PAIRS[name]) return josaFor(previous, name);
        previous = p[name] === undefined ? '' : String(p[name]);
        return previous;
      });
    }

    function t(key, params) {
      const dict = I18N[_lang] || {};
      let value = dict[key];
      if (value === undefined) {
        if (isTestMode()) {
          throw new Error('i18n: нет ключа "' + key + '" для языка ' + _lang);
        }
        value = I18N.ru[key];
        if (value === undefined) return key;
      }
      return _render(value, params);
    }
```

```js
// В коде не должно остаться русского текста вне словарей, комментариев,
// тестов и dev-панели.
const fs = require('fs');
const path = require('path');

const src = fs.readFileSync(path.join(__dirname, '..', 'index.html'), 'utf8');
const lines = src.split('\n');
const CYRILLIC = /[А-Яа-яЁё]/;

// Границы, внутри которых кириллица разрешена.
const bounds = (marker) => lines.findIndex(l => l.includes(marker));
const i18nStart = bounds('=== SECTION: I18N ===');
const i18nEnd = bounds('=== SECTION: TEST INFRA ===');
const devStart = bounds('=== SECTION: DEV ===');

const offenders = [];
lines.forEach((line, i) => {
  const n = i + 1;
  if (n > i18nStart && n < i18nEnd) return;      // словари
  if (devStart !== -1 && n > devStart) return;   // dev-панель
  const code = line.replace(/\/\/.*$/, '');      // комментарии
  if (/\b(describe|it|assert\w*)\s*\(/.test(code)) return;  // тесты
  const literals = code.match(/'[^']*'|"[^"]*"|`[^`]*`/g) || [];
  for (const lit of literals) if (CYRILLIC.test(lit)) offenders.push(n + ': ' + lit);
});

if (offenders.length) {
  console.log('Русский текст вне словаря — ' + offenders.length + ':');
  for (const o of offenders) console.log('  ' + o);
  process.exit(1);
}
console.log('OK: русского текста вне словаря нет');
```
